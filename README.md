# Словарик · RU ↔ 中文

**Приложение:** <https://slovar-app.github.io/slovar/>

Личный офлайн-словарь русско-китайских фраз. Данные хранятся **только в памяти
телефона**, без облака и аккаунтов. Приложение ставится иконкой на рабочий стол и
работает без интернета.

С версии 2.5.1 при первом запуске добавляются примеры: теги **«Приветствие»**,
**«Работа»**, **«Универсальные фразы»** и диалог **«Знакомство»**. Их можно изменить
или удалить. Старые стартовые фразы при обновлении удаляются однократно, перед этим
автоматически создаётся резервная копия.

## Что умеет

- **Теги-ситуации**: главный экран — плитки тегов, тап открывает список фраз.
- **Свои теги**: создаются прямо в форме; переименование, объединение, закрепление и
  удаление — «Ещё → Управление тегами».
- **Добавление и заметки**: китайский, пиньинь (подставляется сам), перевод, теги,
  заметка. Кнопка «Ещё» сохраняет и сразу открывает следующую форму.
- **Поиск**: быстрые группы «Слова» и «Теги» по 3 варианта, отсортированные по
  совпадению, плюс «Глобальный поиск» со всеми совпадениями. По-русски — с опечатками
  и без окончаний; также по-китайски, пиньинем и инициалами (`nh`).
- **Топики**: отдельная вкладка для диалогов и текстов — название, китайский +
  перевод, пиньинь автоматически, озвучка всего текста.
- **Избранное**: звёздочка на фразе, отдельный экран, массовое удаление.
- **История версий**: добавления группируются по часам; можно посмотреть состав
  версии, удалить отдельные фразы или откатить версию.
- **Резервные копии**: автоматический полный снимок раз в неделю (фразы и топики),
  ручные копии, скачивание JSON.
- **Облако временно скрыто**: данные остаются на телефоне; интеграция сохранена в коде
  на будущее, но раздел и загрузки отключены.
- **Сортировка и фильтры**: новые/старые, по-русски, по пиньиню; фильтры
  «Избранные» и «Заметки».
- **Дубликаты**: проверка при вводе и отдельный экран поиска совпадений.
- **Массовое удаление** с отменой: «Выбрать» → галочки → «Удалить (N)» → «Отменить».
- **Ввод пачкой**: «Ещё → Добавить списком», формат `китайский; перевод; тег`.
- **Вставка из буфера** и **«Поделиться»** из браузера/Telegram прямо в форму.
- **Озвучка** (🔊, настройка скорости) и **диктовка** (🎤, нужен интернет).

## Установка на телефон

1. Откройте адрес приложения в **Chrome** на Android.
2. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
3. Подтвердите — на рабочем столе появится «Словарик».

После первого открытия приложение работает офлайн.

**Про адресную строку.** В обычной вкладке Chrome её скрыть нельзя. Она исчезает
только в установленном приложении: откройте сайт → ⋮ → **«Установить приложение»**
(не «Добавить на главный экран») → запускайте с иконки. Если уже добавляли ярлык и он
открывается в браузере, удалите его и установите заново. На главной есть подсказка
«Открыть без адресной строки».

## Поделиться приложением

**Настройки → «Поделиться приложением»**.

- **«Поделиться ссылкой»** открывает системное меню Android: Telegram, WhatsApp, почта.
- **«Скопировать»** кладёт ссылку в буфер обмена.
- **QR-код** можно показать с экрана или отправить картинкой.

Ссылка нейтральная — без имени и названия аккаунта. У каждого, кто установит
приложение, будет свой отдельный словарь; чужие фразы он не увидит. Чтобы передать
конкретные фразы, используйте экспорт/импорт JSON.

## Перенос на новый адрес

При смене адреса сайта данные **не переезжают автоматически** — у браузера отдельное
хранилище для каждого адреса.

1. На старом адресе: **Настройки → «Экспорт в файл»**.
2. Откройте новый адрес, установите приложение.
3. **Настройки → «Импорт из файла» → «Заменить»**.
4. Удалите старую иконку и добавьте новую.

## Первый запуск

При первом запуске уже есть примеры:

- тег **«Приветствие»** — 你好 / Привет;
- тег **«Работа»** — 分析师 / Аналитик;
- тег **«Универсальные фразы»** — 谢谢 / Спасибо;
- топик **«Знакомство»** с диалогом Мао и Ли.

Это обычные записи: их можно редактировать, дополнять и удалять. Свои фразы
добавляйте кнопкой **«+»** внизу — тег можно создать прямо в форме.

## Обновления

```bash
cd /Users/andrey/Desktop/Slovar
./deploy.sh "что изменилось"
```

Или дважды кликните **«Опубликовать обновление.command»**. GitHub Pages обновляется
около минуты, телефон подхватывает новую версию при следующем открытии с интернетом.

## Избранное

- Звёздочка на карточке фразы и в форме редактирования.
- На главном экране — карточка **«Избранное»** со счётчиком.
- В избранном можно нажать **«Выбрать»** и удалить несколько фраз сразу — с отменой.

## Топики

Вкладка **«Топики»** в нижней панели — для диалогов и текстов.

- **«+»** добавляет топик: название (необязательно), китайский текст/диалог и русский
  перевод.
- **Пиньинь** генерируется автоматически при сохранении и показывается под текстом
  в просмотре (в форме ввода его нет — он подставляется сам).
- **«Слушать»** озвучивает весь китайский текст.
- Список сортируется по дате изменения; топик можно открыть, изменить или удалить.
- Топики входят в резервные копии и экспорт JSON.

## Поиск

- При вводе показываются две быстрые группы: **«Слова»** и **«Теги»**, по 3 варианта.
- Внутри групп — сортировка по совпадению: точное (100%) → слово (95%) → начало
  (90%) → вхождение (80%) → основа (65%) → опечатка (45%).
- Кнопка **«Глобальный поиск»** показывает все совпадения с той же сортировкой.
- Опечатки и окончания учитываются; точные совпадения не смешиваются с похожими.

## Теги

- **Закрепление**: «Ещё → Управление тегами» → кнопка-пин. Закреплённые теги
  показываются первыми на главном экране.
- **Объединение**: кнопка ⇄ у тега → выберите, в какой тег объединить. Все фразы
  сохранятся, лишний тег исчезнет.
- Переименование в уже существующий тег тоже объединяет их.
- Удаление тега убирает его у всех фраз; сами фразы остаются.

## История и версии

**«Ещё → История и версии»**.

- Все добавления в течение **часа после первого** попадают в одну версию: если
  добавлять группы фраз каждые 5 минут, версия остаётся одной.
- В версии видно, какие фразы добавлены. Каждую можно удалить отдельно (корзина) —
  остальные останутся.
- Если фраза уже удалена из словаря, в версии есть кнопка **«Вернуть»**.
- **«Откатить версию»** убирает фразы этой и всех более новых версий. Перед откатом
  автоматически создаётся резервная копия, так что откат тоже можно вернуть.

Версии фиксируют **добавления фраз**. Полное состояние словаря (включая правки и
топики) сохраняют недельные копии.

Версии и копии **старше 30 дней удаляются автоматически** при открытии приложения.
Последняя резервная копия сохраняется, даже если она старше месяца.

## Резервные копии

- Полный снимок словаря создаётся автоматически при открытии приложения, если прошло
  больше 7 дней. Хранятся 12 последних копий, но не дольше 30 дней (последняя копия
  сохраняется всегда).
- Можно создать копию вручную и **скачать JSON** на случай потери телефона.
- Восстановление копии заменяет текущий словарь, но перед этим создаётся ещё одна
  копия.

Недельные копии хранятся **в памяти телефона**. Если телефон потеряется, спасёт только
скачанный JSON-файл.

## Облако

Раздел «Облако» временно скрыт: приложение ничего никуда не отправляет, все данные
остаются в памяти телефона. Интеграция с Яндекс Диском сохранена в коде на будущее —
когда понадобится, её можно включить снова.

## Сортировка и фильтры

- Сортировка: **сначала новые / старые / по-русски (А–Я) / по пиньиню (A–Z)**.
  Выбор запоминается.
- В теге — фильтры **«Избранные»** и **«Заметки»**, можно комбинировать.
  Есть «Сбросить фильтры».
- В избранном — только сортировка.

## Дубликаты

При добавлении приложение ищет совпадения:

- точный дубликат (тот же китайский и перевод) добавить нельзя — откроется
  существующая запись;
- похожая фраза (совпадает китайский или перевод) показывается подсказкой, но добавить
  можно, если это действительно другая фраза.

Уже накопившиеся дубликаты: **«Ещё → Дубликаты»**. Там можно удалить лишние записи или
нажать «Оставить одну» — теги и заметки объединятся.

## «Поделиться» из других приложений

1. Выделите текст в браузере, Telegram или другом приложении.
2. «Поделиться» → **«Словарик»**.
3. Форма откроется с заполненными полями — выберите тег и сохраните.

Одна строка → форма «Одна фраза» (понимает `你好 — Привет`, `你好; Привет`), несколько
строк → режим «Списком». Если «Словарика» нет в системном списке, откройте приложение
с интернетом и закройте-откройте его ещё раз.

При долгом нажатии на иконку приложения есть ярлык **«Добавить фразу»**.

## Данные и приватность

- Фразы, теги, заметки, топики, история и копии хранятся в `localStorage` браузера
  телефона (ключ `slovar.v1`).
- Приложение не отправляет данные никуда: ни аналитики, ни серверов, ни аккаунтов.
  Сеть нужна только для загрузки самого приложения с сайта и для диктовки.
- Очистка данных сайта в Chrome удалит словарь — сначала сделайте экспорт.
- Экспорт/импорт JSON — единственный способ перенести словарь на другое устройство.

## Публикация

Приложение размещено на **GitHub Pages**: <https://slovar-app.github.io/slovar/>.
Исходники хранятся в локальной папке и в репозитории
<https://github.com/slovar-app/slovar>.

Обновить после правок:

```bash
./deploy.sh "что изменилось"
```

Скрипт коммитит изменения, отправляет их в репозиторий и обновляет
GitHub Pages. Или дважды кликните
**«Опубликовать обновление.command»**. Новую версию телефон подхватит при следующем
открытии с интернетом.

```

```

## Технические детали

- Ванильный JS без сборки и зависимостей.
- Данные: `localStorage`, ключ `slovar.v1`; экспорт — обычный JSON.
- Пиньинь: [pinyin-pro](https://github.com/zh-lx/pinyin-pro) 3.29.5, локально.
- Озвучка: Web Speech API; на Android нужен китайский голос (Настройки → Язык и ввод →
  Синтез речи → Google).
- Диктовка: Web Speech API (Chrome), распознавание использует сервис Google — нужен
  интернет.
- Обновления: service worker отдаёт сеть, кэширует ответы и работает офлайн.
- Версии и копии: до 100 версий добавлений и 12 полных копий; всё старше 30 дней
  удаляется автоматически, последняя копия сохраняется. При переполнении памяти старые
  данные сокращаются.
- Тесты: Playwright (локально, в `tools/`, в репозиторий не входят).
